📖 Hướng Dẫn Đặt Biến Jinja Trong File Word Bất Kỳ

1. Cơ chế hoạt động:

Bạn có thể dùng BẤT KỲ file Word (.docx) nào (tài liệu kỹ thuật, kế hoạch release, biên bản, hợp đồng...). Chỉ cần điền các thẻ biến Jinja2 vào nội dung Word, tool sẽ tự động đọc file và tạo ra form nhập liệu tương ứng 100% trên màn hình!

2. Cách đặt Biến Đơn (Text / Đoạn văn):

Gõ tên biến bọc trong 2 cặp ngoặc nhọn {{ ... }} vào bất kỳ đâu (trang bìa, bảng thông tin, header, footer hoặc trong nội dung):

Tên dự án: {{ ten_du_an }}
Người lập: {{ nguoi_lap }}
Ngày cập nhật: {{ ngay_lap }}
Mục tiêu bài toán: {{ muc_tieu }}
Kiến trúc tổng thể: {{ kien_truc }}
💡 Mẹo: Nếu tên biến có chữ 'mota', 'mục tiêu', 'nội dung', 'kien_truc', 'notes'... web sẽ tự động hiển thị ô nhập nhiều dòng (textarea) rất tiện lợi!
3. Cách đặt Vòng Lặp cho Bảng (Bảng có số dòng tăng giảm tùy ý):

Để bảng tự động sinh thêm dòng theo số bước bạn nhập trên Web, trong bảng Word bạn thiết kế 4 dòng:

Dòng 1 (Tiêu đề): | STT | Thời gian | Tác vụ thực thi | Người phụ trách | Kết quả mong đợi |
Dòng 2: | {%tr for b in danh_sach_buoc %} | (đặt ở ô đầu tiên)
Dòng 3 (Data): | {{ loop.index }} | {{ b.thoi_gian }} | {{ b.tac_vu }} | {{ b.nguoi_lam }} | {{ b.ket_qua }} |
Dòng 4: | {%tr endfor %} | (đặt ở ô đầu tiên)
💡 Tool sẽ tự nhận diện danh_sach_buoc là bảng động và sinh ra bảng trên Web với các cột: thoi_gian, tac_vu, nguoi_lam, ket_qua kèm nút ➕ Thêm dòng!
4. Sử dụng file Word:

Bạn có thể bấm nút "📤 Tải Lên File Word Mẫu Mới (.docx)" ngay trên thanh công cụ để đưa file vào tool, hoặc copy file vào thư mục templates/.
